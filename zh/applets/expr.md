# expr — 评估表达式

> **其他语言：** [English](../../en/applets/expr.md)

## 语法

```
expr EXPRESSION
```

## 描述

`expr` Applet 评估表达式并将结果输出到标准输出。它支持算术、比较、逻辑和字符串操作。

返回值：
- **0** — 结果非空且非零
- **1** — 结果为空或零
- **2** — 语法错误

## 运算符

### 算术运算

| 运算符 | 描述 |
|--------|------|
| `+` | 加法 |
| `-` | 减法 |
| `*` | 乘法 |
| `/` | 整数除法 |
| `%` | 取模（余数） |

### 比较运算

| 运算符 | 描述 |
|--------|------|
| `=` | 等于 |
| `!=` | 不等于 |
| `<` | 小于 |
| `<=` | 小于等于 |
| `>` | 大于 |
| `>=` | 大于等于 |

### 逻辑运算

| 运算符 | 描述 |
|--------|------|
| `\|` | 或 — 返回第一个非空非零值 |
| `&` | 与 — 若两边非空非零则返回第一个值，否则返回 0 |

### 字符串操作

| 函数 | 描述 |
|------|------|
| `length STR` | 返回 STR 的长度 |
| `substr STR POS LEN` | 返回 STR 从 POS（从 1 开始）起长度为 LEN 的子串 |

## 示例

```bash
# 算术运算
idlebox expr 1 + 2          # => 3
idlebox expr 10 - 3         # => 7
idlebox expr 5 '*' 4        # => 20（引号防止 shell 通配）
idlebox expr 10 / 3         # => 3（整数除法）
idlebox expr 10 % 3         # => 1

# 比较运算
idlebox expr 5 > 3          # => 1（真）
idlebox expr 5 = 5          # => 1（真）
idlebox expr "abc" = "abc"  # => 1（字符串比较）

# 逻辑运算
idlebox expr 0 '|' 5        # => 5（第一个非零值）
idlebox expr 3 '&' 5        # => 3（两边非零，返回第一个）
idlebox expr 0 '&' 5        # => 0（一边为零）

# 字符串操作
idlebox expr length hello   # => 5
idlebox expr substr hello 2 3  # => "ell"
```

## 实现说明

- 位于 `src/applets/expr.rs`
- 使用递归下降解析，具有正确的运算符优先级
- 比较运算符优先尝试数值比较，失败后回退到字符串比较
- `*` 运算符在 shell 中需要引号或转义以避免通配符展开
- 仅使用 Rust 标准库
