# wc — 打印每个文件的换行符、单词和字节数

> **其他语言：** [English](../../en/applets/wc.md)

## 语法

```
wc [选项]... [文件]...
```

## 描述

`wc` Applet 打印每个文件的换行符、单词和字节数。不指定文件或文件为 `-` 时，从标准输入读取。指定多个文件时，末尾会打印 `total` 汇总行。支持并行多线程计数，在处理多个文件时显著提升性能。

## 选项

| 选项 | 描述 |
|------|------|
| `-l`, `--lines` | 打印换行符数 |
| `-w`, `--words` | 打印单词数 |
| `-c`, `--bytes` | 打印字节数 |
| `-m`, `--chars` | 打印字符数 |
| `-j`, `--threads N` | 使用 N 个线程进行并行计数（默认：自动检测 CPU 核心数） |

未指定选项时，`wc` 默认打印行数、单词数和字节数。

## 并行计数引擎

`-j` / `--threads` 选项启用基于 Rust 标准库线程的并行文件计数。处理多个文件时，工作负载会分配到多个工作线程，显著提升吞吐量。

**核心特性：**
- 未指定 `-j` 时自动检测 CPU 核心数
- 有序结果收集保持正确的每文件输出顺序
- 跨所有线程的精确总计计算
- 标准输入或单文件时回退到单线程模式
- 可通过 `-j N` 显式设置线程数（例如 `-j 4` 表示 4 个线程）

**性能优势：**
- 多文件计数随可用 CPU 核心数线性扩展
- 大文件从并行 I/O 操作中获益
- 零外部依赖 - 纯 Rust 标准库实现

## 退出状态

| 退出码 | 含义 |
|--------|------|
| 0 | 成功 |
| 1 | 发生错误 |

## 示例

```bash
# 统计文件行数
idlebox wc -l file.txt

# 统计文件单词数
idlebox wc -w file.txt

# 统计文件字节数
idlebox wc -c file.txt

# 默认：行数、单词数、字节数
idlebox wc file.txt

# 从 stdin 管道统计
cat file.txt | idlebox wc -l

# 多个文件（显示总计）
idlebox wc -l file1.txt file2.txt
# 输出:
#       3 file1.txt
#       5 file2.txt
#       8 total

# 使用 4 个线程进行并行计数
idlebox wc -l -j 4 *.txt

# 自动检测线程数的并行计数
idlebox wc -j 8 file1.txt file2.txt file3.txt
```

## 实现说明

- 位于 `src/applets/wc.rs`
- 使用固定 8 KiB 块读取，而非缓冲整个文件
- 仅请求字节数和/或换行符数时跳过 Unicode 解码
- 跨 UTF-8 块边界保持字符和 Unicode 空白单词计数；无效序列遵循有损替换语义
- 多个文件产生 `total` 汇总行
- 输出右对齐，列宽 7 字符
- 并行引擎使用 `std::thread` 和 `std::sync` 原语（零外部依赖）
- 工作分发使用原子索引追踪实现最优负载均衡
